# 京彩回收 · 绿动京城智慧回收平台（App）

基于对「京彩回收」微信小程序全页面深度探索与重构打造的**智慧废物/废品/弃用物回收一站式移动应用（PWA）**。

## ✨ 核心功能模块与体验升级

1. **首页（绿动京城总览）**
   - 定制 3D 黏土风北京天坛生态头图与品牌视觉徽章
   - 社区一键切换（丽岛花园、望京、回龙观、中关村等）+ 个人环保碳账本速览（环保积分、累计减碳、累计收益）
   - 四大核心业务入口：**可回收物交投**、**大件垃圾预约**、**装修垃圾预约**、**家电回收预约**
   - **今日回收参考价**实时行情条 + **垃圾分类查一查**快捷入口

2. **可回收物交投（全渠道闭环）**
   - **智能回收机 / 固定交投点 / 中转站（分拣中心）**：支持 `500m / 1公里 / 3公里 / 5公里` 筛选、**地图视图与列表视图切换**、柜体余量实时进度条与一键导航/扫码投递
   - **预约上门交投**：选择回收地址与服务企业、多品类重量增减（自动校验 ≥5kg 提示）、实时预估收益与积分计算、照片上传及备注下单

3. **大件垃圾预约清运**
   - 补全原小程序缺失的物品清单与**透明参考价格表弹窗（`价格表>>>`）**
   - 支持常见大件家具数量增减、有无电梯及楼层步梯搬运费自动测算、现场照片上传（最多4张）与实时估价

4. **装修垃圾清运服务（统一设计体系）**
   - 彻底整合原版割裂的外部 H5 页面，打造两步预约向导（选择小区/日期/按袋或按立方米估量 → 选择正规持证处置场）
   - **收运处服务单位名录**：支持搜索与按订单量/距离/评分排序，公示信用等级与透明收费标准弹窗
   - **垃圾分类政策法规 / 投放指南 / 活动信息**：内置完整文章阅读器

5. **家电回收预约**
   - 对接 **京东回收 / 中再生回收 / 京彩绿色直收**，从简单选择弹窗升级为**完整估价预约流**
   - 支持品类选择、机器成色状态、免费拆机开关、环保加价补贴与积分实时计算

6. **统一订单中心 & 个人中心**
   - **全品类订单管理**（修复原版缺失大件/装修分类的问题），内置服务追踪时间轴、取消预约与**「模拟完成结算」**体验闭环
   - **扫一扫模拟开箱投递** + **居民动态交投二维码**（60s自动刷新 + 扫码增亮）
   - **个人资料完善**、**地址管理 CRUD**、**环保积分兑换商城**、**使用说明 + 智能垃圾分类实时查询器**（彻底修复原版空白页）及用户/隐私协议

## 🚀 本地运行

```bash
npm install
npm run dev
```

访问 `http://localhost:5173` 即可在桌面端手机预览框架或移动端浏览器中体验（支持 PWA 添加到主屏幕）。

## 🏗️ 生产构建

```bash
npm run build
npm run preview
```

## 🛠️ 技术栈

- React 19 + TypeScript + Vite
- Tailwind CSS v4 + Lucide Icons
- LocalStorage 状态持久化 + PWA Manifest
