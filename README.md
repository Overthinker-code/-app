# 宁回收 · 南京生活回收与清运服务（App）

面向南京市居民的可回收物交投、大件家具清运、装修垃圾规范清运及废旧家电回收移动应用（React + TypeScript + Vite + Tailwind CSS + Leaflet + QRCode）。

## 功能模块

- **南京本地化服务覆盖**：内置玄武、鼓楼、建邺、秦淮、栖霞、江宁、江北新区小区与点位数据，依据《南京市生活垃圾管理条例》提供分类检索、本地参考行情及备案处置单位名录。
- **可回收物交投**：支持 `500m / 1km / 3km / 5km` 附近智能回收柜、固定交投点与分拣中心检索，集成 **Leaflet 真实南京街道地图**与列表双视图；支持满 5kg 上门回收预约与实时收益计算。
- **大件家具清运**：常见家具品类计数下单、参考价目表弹窗、无电梯楼层人工搬运费自动核算与现场照片上传。
- **装修垃圾清运**：两步预约向导（小区/按袋或按立方米估量 → 选择南京城管备案处置单位）、备案单位口碑与收费标准查询、政策法规与投放指引阅读。
- **废旧家电回收**：对接苏宁帮客、京东回收（南京站）、中再生江苏拆解中心，按品类与成色实时估价及免费拆机预约。
- **订单与电子联单**：支持全品类订单筛选、流转时间轴、**真实可扫描电子联单二维码（`qrcode` 生成）**、取消预约与核验结算。
- **居民工具**：扫码开箱称重、60 秒动态刷新实名交投码、地址管理、南京四分类实时查询与 5 题南京特色分类小测验、积分兑换（金陵通/南京地铁出行金、分类袋、清运抵扣券）。
